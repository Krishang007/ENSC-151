# ENSC 151

This repository contains C++ code written for class assignments, exercises, and exams for the ENSC 151 course.

## Code Directory Analysis

The `code` folder is organized into several subdirectories, each focusing on a specific C++ programming concept covered in the course. Here is a breakdown of the contents:

- **basicIO**: Introductory programs focusing on basic input/output operations using `cin` and `cout`. Contains foundational examples like "Hello World", variable manipulation, and basic arithmetic.
- **conditionals**: Exercises demonstrating control flow using `if`, `else if`, `else`, and `switch` statements.
- **Loops**: Contains exercises demonstrating the use of loops (`for`, `while`, `do-while`). Programs include printing geometric patterns (triangles, squares, rectangles), calculating factorials, checking for palindromes, and generating number series.
- **Functions**: Focuses on C++ functions, including both iterative and recursive implementations. Examples include Fibonacci sequence calculations, factorials, Pascal's triangle, and number swapping mechanisms.
- **Arrray**: Contains programs related to array manipulation, searching algorithms (like linear search), and various sorting algorithms (bubble sort, insertion sort, merge sort, quick sort, selection sort). Includes assignments and test data files.
- **Strings**: Exercises related to string manipulation and processing.
- **Vector:lambda**: Covers the use of C++ Standard Template Library (STL) `std::vector` and lambda expressions.
- **fileIO**: Programs that read from and write to external files, demonstrating file stream operations.

### Additional Notes
- Most folders include `.cpp` source files along with compiled binaries (`a.out` or macOS `.dSYM` directories).
- Several directories contain problem statements, assignment descriptions, and cheat sheets in Markdown (`.md`) or PDF format.
